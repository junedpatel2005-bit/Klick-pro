# UI Preferences

- Prefers dropdown (`<select>`) controls over chip-style button groups for category/segment filter pickers. Confidence: 0.85
- Wants dropdowns to include an explicit "All" / reset option as the default selection so users can clear that filter without using a global clear button. Confidence: 0.85
- Prefers multi-level (parent → category → sub-category) hierarchical filtering where each level progressively narrows the listed results to the currently selected node. Confidence: 0.85
