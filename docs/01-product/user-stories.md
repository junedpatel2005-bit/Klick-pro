## Conventions

| Item                     | Convention                                                                                                                                                                                                                                                 |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ID                       | `US-<MOD>-NNN`. MOD codes: AUTH, ACC, CAT, JOB, PROP, PRJ, PAY, DSP, MSG, NOT, VER, SRCH, CMS, RPT, ADM, SYS. Reviews are part of PRJ.                                                                                                                     |
| Grouping                 | By role (Public, Shared client+professional, Client, Professional, Admin), then by module                                                                                                                                                                  |
| Status                   | **Implemented** (verified in code) · **Partial** · **Planned** (in older docs `project-docs/src/routes/docs/Scope_Of_Development_MASTER.md` / `Business_Requirements_Document.md`, no code) · **Unknown**                                                  |
| Acceptance criteria (AC) | Derived from actual server behaviour: validation, status checks, HTTP codes. UI-only gating is labelled as such.                                                                                                                                           |
| Evidence                 | Route (page) · API (`METHOD /api/...`, canonical path without `/v1`) · lib/model                                                                                                                                                                           |
| Traceability             | Stories map to `FR-<MOD>-NNN` in [functional-requirements.md](../02-requirements/functional-requirements.md) by module. Pages are listed in [screen-inventory.md](../06-ui/screen-inventory.md) by route. Business rules `BR-*` are in [BRD.md](./BRD.md). |
