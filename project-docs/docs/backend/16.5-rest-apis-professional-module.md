# 16.5 REST APIs - Professional Module

## Purpose

Allow professionals to create a profile, find work, send proposals, complete project work, and monitor earnings.

## Implemented work

- Professional profile and service information endpoints.
- Identity/verification upload and status endpoints.
- Browse, search, filter, and save marketplace jobs.
- Proposal submission and proposal-status endpoints.
- Running project, milestone, work-proof, and attachment actions.
- Earnings, wallet balance, and withdrawal-request endpoints.

## How to explain it

The professional API module powers the professional work journey: discover jobs, submit a proposal, work on an accepted project, update milestones, and request payout.

## Detailed professional workflow

The professional profile stores public service information, skills, rate, work preferences, and verification status. This data supports discovery by clients and helps the platform determine whether the professional is ready to submit proposals.

The job-discovery endpoints provide open client jobs with category, work-mode, location, budget, and search filters. Professionals can save relevant jobs and open a full job-detail view before submitting a proposal. The proposal endpoint validates that the job is open, that the user is a professional, and that duplicate or invalid submissions are not accepted.

After a proposal is accepted, the professional gains access to the related project workspace. The workspace shows project status, milestones, remaining work, attachments, and money-related information. When the professional submits work proof or updates a milestone, the client can be notified to review it. Once approved, the wallet and earnings data reflects the valid completed amount according to the platform’s rules.

## Data protection and visibility

Professionals can browse public open jobs but cannot view private proposals submitted by other professionals. They can access private project information only for a project to which they are assigned. This prevents data leakage between competing service providers.

## Presentation example

Explain the professional module as the “supply side” of the marketplace. It turns a professional from a registered account into a verified provider who can discover opportunities, bid, deliver work, and follow earnings.

## Demonstration

1. Sign in as a professional.
2. Browse jobs with filters.
3. Open a job and submit a proposal.
4. After acceptance, open My Jobs to show running projects, milestones, and earnings.
