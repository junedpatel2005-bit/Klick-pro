# 16.6 REST APIs - Maps & Location

## Purpose

Support accurate job and profile locations for remote and onsite work.

## Implemented work

- Address search and geocoding integration.
- Location picker with map display using Leaflet and OpenStreetMap data.
- Location details stored with jobs and profiles.
- Rate limiting around location search requests.
- Support for remote, onsite, and location-based job discovery.

## How to explain it

The map feature converts an address search into usable coordinates and readable address information. This helps professionals find nearby onsite work and helps clients describe where the work will happen.

## Detailed location flow

When a user searches for an address, the frontend sends a request to the location endpoint rather than directly trusting manually entered coordinates. The backend applies rate limiting to control repeated requests and then uses the configured geocoding source. The selected result is stored as a structured location, typically including formatted address, city/region information, latitude, and longitude.

The map is a visual aid; the database value is the authoritative location data. Jobs also support work modes such as remote and onsite, so the system can filter or display location only where it is relevant. A remote job should not misleadingly appear as a required onsite assignment.

## Why rate limiting matters

Geocoding services are third-party resources with usage limits. Rate limiting prevents accidental excessive calls while typing and limits intentional misuse. In production, API monitoring and provider-specific keys/terms should be configured if a commercial maps provider is used.

## Data and privacy considerations

The application should collect only the location precision necessary for the job. An exact residential address should not be exposed publicly before it is appropriate. Public job cards can show city or remote status, while full location details can be restricted to the job owner, selected professional, or administrator.

## Demonstration

1. Start creating a job or edit a profile.
2. Search for an address in the location picker.
3. Select the result and show the pin on the map.
4. Save the form and show the location on the job/profile detail screen.
